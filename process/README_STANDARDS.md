### Главные правила оформления

1. **Строгий запрет на эмодзи:**
   * В заголовках, тексте и бейджах документации **КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО** использовать эмодзи (никаких 🚀, 📦, 🔥, ⚡). Стиль WHAT Technologies — лаконичный, техничный и монохромный.
2. **Единая палитра Shields.io бейджей:**
   * Фон значения (значение бейджа): `#09090b` (zinc-950).
   * Фон ярлыка (labelColor): `#000000` (чистый черный).
   * Стиль бейджей: `style=for-the-badge`.
   * Высота информационных бейджей: строго `height="24"`.
3. **Иконка проекта в шапке:**
   * Закругление логотипа в шапке: `style="border-radius: 20%;"`.
4. **Диаграммы архитектуры:**
   * Все схемы и зависимости визуализируются через блоки ````mermaid````.
5. **Подвал документа:**
   * Завершается копирайтом по центру:
   ```html
   <div align="center">
   <sub>© WHAT Technologies. Все права защищены.</sub>
   </div>
   ```
